# Go TODO App

## Описание проекта
Данный проект - веб-приложение для управления задачами (TODO-планировщик). 
Оно позволяет пользователю добавлять задачи с указанием даты и правил их повторения (ежедневно, еженедельно, ежемесячно, ежегодно), а также дает возможность искать, редактировать, удалять и помечать задачи как выполенные.

Серверная часть написана на языке Go, в качестве базы данных используется встроенная СУБД SQLite. 
Фронтенд-составляющая (HTML, JS, CSS) расположена в директории `web`.

## Запуск проекта локально
Для запуска приложения локально потребуется установленный Go.

Приложение можно конфигурировать через переменные окружения:
* `TODO_PORT` — порт, на котором будет запущен веб-сервер (по умолчанию `7540`).
* `TODO_DBFILE` — путь к файлу базы данных SQLite (по умолчанию `scheduler.db`).
* `TODO_PASSWORD` — пароль для доступа к веб-интерфейсу (оставьте пустым для отключения аутентификации).

**Пример запуска в Git Bash (или Linux/macOS):**
```bash
# Установка переменных окружения
export TODO_PORT="7540"
export TODO_DBFILE="todo.db"
export TODO_PASSWORD="12345"

# Запуск приложения
go run main.go
```

После успешного запуска откройте в браузере адрес: **http://localhost:7540** (либо тот порт, который вы указали в `TODO_PORT`).

## Сборка и запуск через Docker
В проекте предусмотрен `Dockerfile`, который самостоятельно компилирует приложение и упаковывает его в образ.

**1. Сборка Docker-образа:**
Выполните следующую команду в корне проекта:
```bash
docker build -t todo-app .
```

**2. Подготовка файла базы данных:**
Перед запуском контейнера создайте пустой файл для базы данных на хосте, чтобы при монтировании тома Docker не создал вместо файла директорию:
```bash
touch scheduler.db
```

**3. Запуск контейнера:**
```bash
docker run -d -p 7540:7540 -v "$(pwd)/scheduler.db:/app/scheduler.db" -e TODO_PASSWORD="12345" --name todo-container todo-app
```
После запуска интерфейс планировщика будет доступен в браузере по адресу **http://localhost:7540**.
